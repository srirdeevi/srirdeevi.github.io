About

I started my career as an applications developer — writing code, shipping features, learning how systems actually break in production rather than in theory. From there the path moved through senior software engineer, lead engineer, and software architect, each step pulling me further from writing individual features toward designing how entire systems fit together.

Somewhere in that progression, the industry itself shifted under me — on-premise infrastructure giving way to cloud, monoliths breaking into services — and I moved with it, into hybrid cloud and Zero Trust architecture. That work has spanned financial services, healthcare, and public sector systems for seventeen years now, and at some point along the way, writing about the work became part of the work itself: published research on cloud security, DevSecOps, and AI-driven threat detection, alongside the architecture itself.

The most recent turn in that path started in architecture reviews, of all places — the same design questions resurfacing again and again, answers that existed but were hard to surface. For the past few years, I've been building agentic AI systems to answer a different question: could an agent actually handle this, not just search for it? A tool-use agent, a RAG pipeline, an MCP server, a coding agent that investigates a codebase directly — each one built and documented as I go, the latest step in a path that's always moved toward understanding systems by building them myself.
